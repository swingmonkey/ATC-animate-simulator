# 空管雷达动画模拟器

一个功能完整的空管雷达动画模拟器，用于模拟空中交通管制场景。

## 功能特点

### 📍 航路点管理
- 支持多种类型的航路点：普通点、交叉点、VOR点、导航点、报告点
- 可拖拽添加航路点到地图
- 支持编辑航路点名称和类型

### 🔗 航线管理
- 按序连接航路点创建航线
- 支持自定义航线颜色
- 显示航线距离和航向度数

### ✈ 飞机管理
- 支持添加多架飞机
- 可设置飞机的航班号、应答机、起飞地、目的地、机型、高度、速度、航向
- 三种导航模式：航线导航、自由导航、航向飞行
- 支持飞机关联到航线
- 到达航路点后可选择下一航路点

### ⏱ 时间控制
- 播放/暂停功能
- 可调整播放速度（1x, 2x, 5x, 10x, 60x）
- 拖动进度条可直接跳转到指定时间点
- 飞机位置会根据时间准确计算

### 📻 陆空通话
- 支持管制员广播
- 支持向特定飞机发送指令
- 记录通话历史

### 🗺 地图操作
- 鼠标滚轮缩放地图
- ASWD键或方向键移动地图
- 点击选择飞机、航路点和航线

### ⚙ 设置功能
- 可设置飞机默认参数（高度、速度、机型、应答机）
- 可设置显示参数（网格间距、最小间隔、时间轴长度）

### ❓ 帮助系统
- 详细的工具使用说明
- 按功能分类的操作指南

## 技术实现

- **前端框架**：纯 HTML5 + CSS3 + JavaScript（ES 模块）
- **画布绘制**：Canvas API
- **数据存储**：浏览器 localStorage（场景持久化）+ 内存
- **响应式设计**：适配不同屏幕尺寸

## 快速开始

### 本地运行

1. 克隆项目到本地
   ```bash
   git clone https://github.com/swingmonkey/ATC-animate-simulator.git
   ```

2. 进入项目目录
   ```bash
   cd ATC-animate-simulator
   ```

3. 启动本地服务器
   ```bash
   # 使用Python 3
   python -m http.server 8000
   
   # 或使用Python 2
   python -m SimpleHTTPServer 8000
   
   # 或使用Node.js
   npx http-server -p 8000
   ```

4. 打开浏览器访问
   ```
   http://localhost:8000
   ```

### 基本操作

1. **添加航路点**：从左侧工具栏拖拽航路点到地图，或点击"+ 添加航路点"按钮
2. **创建航线**：点击"🔗 按序连接航路点"按钮，然后依次点击地图上的航路点
3. **添加飞机**：从左侧工具栏拖拽飞机到地图，或点击"+ 添加飞机"按钮
4. **开始模拟**：点击"▶ 播放"按钮开始模拟
5. **调整时间**：拖动时间滑块可查看不同时间点的状态

## 使用指南

### 航路点操作
- **添加**：从工具栏拖拽或点击添加按钮
- **编辑**：双击航路点或在右侧面板中选择
- **删除**：选择航路点后点击删除按钮

### 航线操作
- **创建**：点击连接按钮后依次选择航路点
- **编辑**：双击航线或在右侧面板中选择
- **删除**：选择航线后点击删除按钮

### 飞机操作
- **添加**：从工具栏拖拽或点击添加按钮
- **编辑**：双击飞机或在右侧面板中选择
- **设置导航**：在编辑对话框中选择导航模式和目标
- **关联航线**：将飞机拖拽到航线上

### 时间控制
- **播放/暂停**：点击▶/⏸ 按钮或按空格键
- **调整速度**：使用速度下拉菜单
- **跳转到指定时间**：拖动时间滑块

### 陆空通话
- **选择目标**：从下拉菜单选择发送对象
- **发送指令**：输入指令并点击发送按钮

## 项目结构

```
ATC-animate-simulator/
├── index.html          # 主页面（模块入口 js/main.js）
├── styles.css          # 样式文件
├── js/
│   ├── main.js         # 入口：初始化、动画循环、恢复持久化场景
│   ├── core.js         # 共享状态、坐标工具、localStorage 持久化
│   ├── simulation.js   # 飞机运动模拟、几何与冲突检测
│   ├── render.js       # 雷达画布渲染
│   ├── ui.js           # 对话框、面板、进程单与通讯 UI
│   └── interactions.js # 键盘/鼠标/拖放事件绑定
├── README.md           # 项目说明
└── 其他资源文件
```

> 场景数据（航路点/航线/飞机/默认参数）自动保存到浏览器 localStorage，刷新页面不丢失；
> 需要清空时在浏览器控制台执行 `localStorage.removeItem('atc_simulator_state_v1')`。
